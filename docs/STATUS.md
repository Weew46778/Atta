# Status — MineAva Android MVP

تاریخ: 2026-09-06

## چه چیزهایی این نسخه واقعاً دارد

1. **منوی اصلی لانچر** (`MainActivity`)
   - دکمه باز کردن Minecraft Bedrock (در صورت نصب) یا هدایت به فروشگاه.
   - دکمه گفتگوی صوتی.
   - دکمه فعالسازی پنل اورلای (با بررسی مجوز Overlay).
   - مسیر ساخت/مدیریت سرور، مدیریت پکیج، سلامت و تست سیستم.

2. **راهاندازی خودکار و مجوزها** (`OnboardingActivity`)
   - تست اولیه همهٔ اجزا (Diagnostics).
   - درخواست میکروفن، اعلان، Overlay.
   - پیامهای صوتی راهنما.

3. **دستیار صوتی «آوا»** (`VoiceAssistantActivity`, `assistant/*`)
   - Text-to-Speech فارسی (توسط موتور دستگاه).
   - Speech-to-Text فارسی (توسط Google/موتور دستگاه).
   - ورودی متنی و چت.
   - اول جستجو در دایرةالمعارف محلی، بعد اتصال Gemini در صورت داشتن کلید.

4. **دایرةالمعارف محلی**
   - `app/src/main/assets/knowledge_base.json`
   - شامل موضوعات ماینکرافت: نتریت، انچنت، فارم آهن، فارم XP، ردستون، سرور بدراک، Geyser، کامندبلاک، تجارت روستایی و سازهها.
   - قابل جستجوی آفلاین.
   - **یادگیری پویا**: هر پاسخ آنلاین آوا در `filesDir/knowledge_extra.json` ذخیره میشود تا دفعه بعد آفلاین جواب بدهد.
   - **تحقیق پویا** (`KnowledgeResearchWorker`): موضوعات پرمطالبه ماینکرافت را بهصورت آنلاین جستجو/پرسش میکند و به دایرةالمعارف شخصی اضافه میکند.

5. **پنل اورلای** (`service/OverlayService`)
   - نوار نازک عمودی در لبه چپ صفحه.
   - کشیدن به راست → باز شدن پنل با انیمیشن و لرزش.
   - ۵ زبانه عمودی با رنگهای مختلف.
   - با کلیک هر زبانه، صفحه قبلی به بیرون میَرود و صفحه جدید سر میخورد داخل.
   - کلیک مجدد زبانه باز → جمع شدن.
   - بعد از ۳ ثانیه بیفعالیتی، پنل خودکار جمع میشود.
   - صفحات: ابزار، کد/سازه، سلاح، آوا، سلامت.
   - آیتمهای سلاح/سازه با کلیک کپی میشود (دستور `give` یا طرح فارم).
   - واکشی زندهٔ RAM/حافظه/دما/CPU و پاکسازی کش.

6. **ساخت سرور** (`ServerWizardActivity`, `server/*`)
   - پرسش «کجا؟»: Local یا VPS.
   - نوع: Java / Bedrock / Hybrid.
   - نسخه، رم، حداکثر بازیکن.
   - چکباکس ورود Java/Bedrock، Geyser و Bungee.
   - انتخاب پیشرضوی پلاگینها/مادها/شیدرها.
   - خروجی: فایل `.sh` ذخیره در Download/MineAva + دکمه کپی اسکریپت.
   - ذخیره کانفیگ در `AppPrefs`.

6b. **اجرای واقعی سرور روی VPS** (`server/VpsProvisioner.kt`, `server/SshClient.kt`)
   - اتصال SSH با پسورد یا کلید (و رمز کلید).
   - انتخاب فایل کلید از حافظه دستگاه (کپی به `filesDir/mineava_ssh_key`).
   - تشخیص root/sudo؛ اجرای خودکار با sudo و پسورد غیرتعاملی.
   - آپلود اسکریپت `ServerRecipeGenerator.buildScript()` از طریق SFTP.
   - اجرای اسکریپت و برگرداندن خروجی زنده؛ نمایش + کپی خروجی.
   - مدیریت از راه دور: `ServerManagerActivity` با status / restart / journalctl.
   - **بکاپ خودکار دنیا** با `tar -czf` در `~/minecraft-server/backups`.
   - **آمار VPS**: RAM (`free -m`)، دیسک (`df -h`)، آپتایم.
   - **کنسول واقعی STDIN (tmux)**: سرور زیر سشن `MineAvaServer` اجرا میشود؛ ارسال فرمان با `tmux send-keys`، نمایش خروجی با `tmux capture-pane`، شروع/توقف سرویس، وضعیت سشن.
   - رمز عبور SSH فقط در حافظه نگهداری میشود و در کانفیگ JSON ذخیره نمیشود.

7. **مدیریت پکیج** (`PackageManagerActivity`, `server/PackageCatalog.kt`, `server/PackageDeployer.kt`, `server/PackageCatalogUpdater.kt`)
   - دستهبندی پلاگین/ماد/مودپک/شیدر/تکستچر.
   - لیست پیشنهادی با توضیح و لینک.
   - **چک واقعی لینک**: HEAD/GET، کد HTTP، نوع محتوا و تشخیص «صفحه مرجع» از «فایل مستقیم».
   - **نصب واقعی روی VPS**: دانلود → SFTP آپلود به `plugins`/`mods`/`modpacks`/`resourcepacks` → ریاستارت `MineAva-server`.
   - **حذف واقعی**: SFTP `rm` + ریاستارت.
   - **بروزرسانی خودکار فهرست**: اتصال به GitHub API و Modrinth API برای گرفتن آخرین نسخه + لینک مستقیم؛ ذخیره در `package_catalog_user.json`.
   - **چک سازگاری با نسخه سرور**: بر اساس `compatiblePrefixes` هر پکیج.
   - اگر سرور VPS باشد، از کانفیگ ذخیرهشده و رمز SSH/کلید استفاده میکند.
   - آیتمهای دارای لینک مستقیم یا قابل بروزرسانی خودکار قابل نصب هستند؛ بقیه فقط «مرجع» نشان داده میشوند.

7b. **صدای فارسی داخل اپ** (`VoiceSettingsActivity`, `assistant/TextToSpeechManager`)
   - لیست صداهای فارسی نصبشده روی دستگاه.
   - انتخاب صدای زن (بر اساس نام/نشانه زنانه).
   - انتخاب دستی صدا و ذخیره در `AppPrefs`.
   - دکمه نصب/بروزرسانی داده صوتی فارسی و دکمه ورود به تنظیمات TTS.
   - کنترل سرعت گفتار با SeekBar.

7d. **صدای زن فارسی جاسازی/قابلنصب در اپ** (`assistant/VoicePack.kt`, `assistant/VoicePackInstaller.kt`, `VoiceSettingsActivity`)
   - پشتیبانی از «بسته صوتی ZIP» شامل `voice_pack.json` + فایلهای WAV.
   - نصب بسته از حافظه دستگاه، شمارش فریز، و پخش مستقیم از داخل اپ.
   - تغییر صوت بین TTS سیستم و صدای داخل اپ.
   - به دلیل لایسنس/حجم، خود بستهٔ صوتی در ریپو نیست؛ مسیر کامل نصب در UI باز است.

7e. **سرور بدراک روی خود گوشی** (`server/OnDeviceServerManager.kt`, `server/OnDeviceServerProvisioner.kt`)
   - پوشهٔ `filesDir/ondevice_server`، `server.properties`، `run.sh`.
   - اجرای فرایند با `ProcessBuilder`، توقف، وضعیت PID و خواندن لاگ.
   - نصب باینری از ZIP کاربر (`OnDeviceServerProvisioner.installZip`).
   - اجرای موفق به معماری گوشی و باینری ARM سرور وابسته است؛ در صورت ناسازگاری خطای دقیق گزارش میشود.

8b. **پنل حرفهای سرور** (`ServerPanelActivity`)
   - وضعیت، شروع/توقف، کنسول/لاگ، منابع، بکاپ، لینک پکیج و مدیریت قبلی در یک صفحه.
   - برای VPS از SSH/tmux؛ برای گوشی از مدیر on-device استفاده میکند.
7c. **ساخت/ارسال دستور بدراک از پنل اورلای** (`server/BedrockCommandBuilder`, `Service/OverlayService`)
   - تولید دستورهای سازگار با بدراک (`give`/انچنت/تخم اسپان).
   - کپی در کلیپبورد.
   - اگر سرور VPS با کلید SSH ذخیرهشده فعال باشد، دستور به کنسول tmux ارسال میشود.
   - (اینجکشن مستقیم داخل کلاینت بدراک از API عمومی ممکن نیست و انجام نمیشود.)

8. **سلامت دستگاه و عیبیابی** (`system/*`)
   - RAM، حافظه، دما، CPU، کش.

   - تست همهٔ اجزا + گزارش متنی + کپی در کلیپبورد.


7f. **بستهٔ نمونهٔ صوتی داخل اپ** (`assistant/VoicePackSample.kt`, `tools/make_sample_voice_pack.py`)

## چیزهایی که عمداً به «پیشخوان/بعدی» گذاشتم

- **اجرای واقعی سرور روی خود گوشی**: نیاز به Bedrock Server runtime داخل اپ دارد.
- **دانلود/نصب تمام پکیجهای کاتالوگ**: فقط آیتمهای دارای لینک مستقیم یا قابل بروزرسانی خودکار نصب میشوند؛ بعضی مودپکها/پکها API عمومی ندارند.
- **تزریق مستقیم آیتم/دستور داخل خود کلاینت بدراک**: با API عمومی اندروید ممکن نیست. راهحل فعلی «ساخت دستور + ارسال به کنسول سرور / کلیپبورد» است.
- **بررسی سازگاری نسخه**: با metadata هر پکیج (GitHub/Modrinth) چک میشود؛ اما برای مودپکهای بدون API عمومی دستی است.
- **جاسازی موتور TTS اختصاصی زن فارسی در APK**: به دلیل لایسنس/حجم هنوز نشده؛ بهجایش صفحه انتخاب صدای فارسی و نصب داده صوتی از سیستم فراهم است.
- **ماکروهای واقعی محیط بازی**: فقط ساخت دستور، کپی و ارسال به کنسول سرور انجام میشود.

## نکتهای درباره چند درخواست

خواستههای «ربات هوشمند که داخل بدراک حضور فیزیکی داشته باشد»، «سرور را کاملاً خودکار روی VPS بسازد»،
«همهٔ پیشنیازها را داخل خودش بگذارد» و «خودش را خودکار از اینترنت ارتقا بدهد» از هر نظر که درست
بسازند، به چند پیشنیاز مهم نیاز دارند (API بدراک، SSH، موتور LLM/پیکرهٔ صدا، Storage و Worker).
این نسخه پایه را طوری چیدهام که این قابلیتها بعداً بدونrewrite شدن UI وصل شوند.

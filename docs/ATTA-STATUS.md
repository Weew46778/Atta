# وضعیت آتا — کنسول واقعی سرور ماینکرافت (نسخهٔ ۱٫۱٫۰)

آخرین بررسی: ۱۴ سپتامبر ۲۰۲۶ — ۴۴ آزمون Node موفق، ۹ آزمون مرورگری آتا موفق (شامل اتصال واقعی به پنل موک‌شده و مسیر پل اورلای بومی).

## نسخهٔ ۱٫۱٫۰ — اتصال واقعی به‌جای شبیه‌سازی

### ۱) مدیریت واقعی سرور روی میزبان‌ها (پنل پتروداکتیل)
بیشتر میزبان‌های فهرست (PebbleHost، FalixNodes، GodLike، BisectHosting و…) پنل **پتروداکتیل** دارند. آتا کلاینت کامل API رسمی پنل است (`src/atta/real/pterodactyl.js`) و با «نشانی پنل + کلید API کاربر» واقعاً وصل می‌شود:
- **فهرست سرورهای واقعی** حساب، با نشانی آی‌پی/پورت و گره — `GET /api/client`
- **وضعیت و منابع زنده** (تی‌پی‌اس، رم، سی‌پی‌یو) — `GET /api/client/servers/{id}/resources`
- **روشن/خاموش/ری‌استارت واقعی** — `POST /api/client/servers/{id}/power`
- **ارسال دستور واقعی به کنسول** — `POST /api/client/servers/{id}/command` (همین مسیر یک‌لمسی اورلای است)
- **کنسول زنده با وب‌سوکت رسمی** و بازاتصال خودکار — `GET /api/client/servers/{id}/websocket`
- **بکاپ واقعی در پنل میزبان** — `POST/GET /api/client/servers/{id}/backups`
- کلید فقط روی دستگاه کاربر ذخیره می‌شود؛ راهنمای ساخت کلید داخل اپ هست.

### ۲) وی‌پی‌اس اترنوس / هر وی‌پی‌اس دیگر — ساخت واقعی سرور
«عامل آتا» (`server/atta-agent.mjs`، بدون وابستگی، فقط Node) یک‌بار روی وی‌پی‌اس اجرا می‌شود. از آن پس اپ:
- **سرور واقعی می‌سازد**: دانلود هستهٔ رسمی بدراک (BDS) یا پیپر، نوشتن `server.properties` و آماده‌سازی
- روشن/خاموش/ری‌استارت واقعی، نوشتن دستور واقعی در کنسول فرایند، دمیدن لاگ، بکاپ از پوشهٔ جهان
- داخل اپ، دستور نصب یک‌خطی برای کپی هست.

### ۳) اورلای واقعی روی خود بازی (اندروید بومی)
سرویس بومی `OverlayService` با مجوز `SYSTEM_ALERT_WINDOW` **روی خود ماینکرافت** رسم می‌شود — نه داخل وب‌ویو:
- دستگیرهٔ لبهٔ چپ قابل جابه‌جایی، ۹ زبانهٔ رنگی نیمه‌شفاف با انیمیشن، پنل کشویی کنار زبانه، بستن خودکار ۳۰ ثانیه با شمارشگر
- هر دکمه یک دستور واقعی بدراک است (گیم‌مود، زمان، آب‌وهوا، `/give`، `/effect`، `/summon`، `/kill @e`…)؛ چند دستور با «;» پشت‌سرهم؛ عمل‌های سطح پنل (`@power:`، `@backup`) هم روی دکمه‌هاست
- لمس دکمه → پل محلی `127.0.0.1:48273` → وب‌ویوی اپ → کلاینت واقعی → سرور واقعی. نتیجه با توست روی بازی دیده می‌شود
- بقیهٔ صفحه برای بازی آزاد است (`FLAG_NOT_FOCUSABLE`)

### ۴) مسیر یک کلیک: از اورلای تا سرور واقعی
`پنل واقعی ← هدف اورلای ← دکمهٔ اورلای داخل بازی` — در آزمون مرورگری اثبات شده که کلیک روی دکمهٔ اورلای، `POST /command` با بدنهٔ درست به پنل می‌فرستد و `realPower` هم `POST /power` واقعی می‌زند.

### ۵) اترنوس رایگان (Aternos) — صادقانه
اترنوس هیچ API رسمی ندارد و طبق قوانینش استفاده از ابزار خودکار غیررسمی باعث **حذف سرور و مسدودشدن حساب** می‌شود (پاسخ رسمی پشتیبانی اترنوس هم همین است). آتا عمداً این ریسک را نمی‌کند و به‌جایش مستقیم پنل خود اترنوس را باز می‌کند.

## هنوز شبیه‌سازی است (مسیر «ساخت با جادوگر»)
جادوگر ۱۰ مرحله‌ای و سرورهای ساخته‌شده با آن برای برنامه‌ریزی و تمرین‌اند؛ ساخت سفارش واقعی روی میزبان‌های پولی نیازمند پرداخت در فروشگاه میزبان است و از کلید کلاینت پنل ممکن نیست. پنل آن سرورها همچنان کامل کار می‌کند.

## صدا
صدای زن فارسی «آوا» (۱۰ گفتار ضبط‌شده همراه بسته)، کنترل صوتی با کلمهٔ بیداری «آتا»، ورودی متنی جایگزین وقتی شناسایی گفتار دستگاه در دسترس نیست.

## آزمون‌ها
- `tests/atta.test.js` (۱۴) + `tests/atta-real.test.js` (۹): قرارداد درخواست‌ها دقیقاً مطابق مستندات/کد رسمی پتروداکتیل، با ترانسپورت موک
- `tests/browser/atta.spec.js` (۷): رفتار دقیق اورلای + جادوگر + پنل
- `tests/browser/atta-real.spec.js` (۲): اتصال به پنل موک‌شده در سطح شبکه، کلیک اورلای → `/command`، پل بومی اندروید → دستور تکی و چندگانه

## نصب روی گوشی
`releases/Atta-Console-v1.1.0.apk` — بعد از نصب، برای اورلای واقعی: دکمهٔ «بازکردن اورلای روی بازی» → اجازهٔ «نمایش روی برنامه‌ها» را برای آتا روشن کنید. نصب روی گوشی/شبیه‌ساز در این محیط تست نشده؛ امضا و ساختار فایل تأیید شده است. کلید امضا در گیت نیست.

## ساخت دوباره
```sh
bash scripts/setup-android-tools.sh
# کلید: .tools/atta-local.p12 با نام مستعار atta (مثل دستورهای اسکریپت)
export KEYSTORE_PASSWORD='...'
bash scripts/build-atta-apk.sh
```

```
src/atta/real/vps-agent.js     کلاینت عامل وی‌پی‌اس
server/atta-agent.mjs          عامل واقعی سمت وی‌پی‌اس (ساخت/اجرا/بکاپ سرور)
android/atta/.../OverlayService.java   اورلای بومی روی بازی
android/atta/.../MainActivity.java     پل محلی ۱۲۷٫۰٫۰٫۱ و لانچ بازی‌ها
```

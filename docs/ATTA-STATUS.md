# وضعیت آتا — کنسول سرور ماینکرافت (نسخهٔ ۱٫۰٫۰)

آخرین بررسی: ۱۴ سپتامبر ۲۰۲۶ — ساخت وب و ساخت موفق، ۳۵ آزمون Node و ۷ آزمون مرورگری آتا موفق؛ ۲ آزمون مرورگری نسخهٔ قبلی هم به‌عنوان نمونهٔ عدم رجرفسیون موفق.

## چه چیزی ساخته شده؟

**اپ اندروید «آتا»** (`releases/Atta-Console-v1.0.0.apk`، بستهٔ `ir.atta.console`):
- رابط وب آفلاین فارسی/راست‌به‌چپ که با همان خط لولهٔ سبک پروژه (بدون Gradle) بسته‌بندی و امضا شده است.
- طراحی «یک صفحه، بدون اسکرول»: هر صفحه یک قاب ثابت با دکمه‌های درشت؛ ادامهٔ کار در صفحهٔ بعد.

### ۱) ساخت و استقرار سرور
- **۱۱ میزبان** داخل اپ: اترنوس رایگان، وی‌پی‌اس اختصاصی «اترنوس»، پلاودوس، فالیکس‌نودز، پبل‌هاست، شاک‌بایت، ایپکس، بایسکت، گادلایک، نودکرافت و اسکالاکوب — با قیمت، رم، دیتاسنتر، پینگ، پشتیبانی و نوع پنل.
- جادوگر ساخت قدم‌به‌قدم (۱۰ مرحله، هر مرحله یک سؤال) با گفتار راهنما: نام، نسخه (بدراک/جاوا/کراس‌پلی)، نسخهٔ بازی، حالت، سختی، تعداد بازیکن، رم، منطقهٔ دیتاسنتر، بازبینی و استقرار.
- استقرار شبیه‌سازی‌شدهٔ زنده با ۸ مرحله (اختصاص منابع، دانلود هسته، نوشتن تنظیمات، گیسر، فایروال و…) و سپس روشن‌شدن خودکار سرور.

### ۲) پنل مدیریت کامل داخل اپ
- نمای کلی: وضعیت، تی‌پی‌اس، بازیکن، رم، آپ‌تایم، روشن/خاموش/ری‌استارت.
- کنسول زنده با اجرای دستور.
- بازیکن‌ها: اوپ/دی‌اوپ، وایت‌لیست، کیک، بن/آزادسازی.
- تنظیمات دقیق: ۲۱ کلید `server.properties` در ۴ گروه (عمومی، شبکه، جهان، کارایی).
- بکاپ: پشتیبان‌گیری فوری، فهرست و بازگردانی.

### ۳) اتصال به بازی
- صفحهٔ «ورود به بازی»: نمایش و کپی خودکار نشانی/پورت.
- در اپ اندروید، دکمه‌ها لانچر واقعی را باز می‌کنند: ماینکرافت بدراک (`minecraft://`) و لانچر پوجاو (بوجاو/جاوا)؛ اگر نصب نباشند مسیر فروشگاه باز می‌شود. در وب، شبیه‌ساز داخلی برای تمرین هست.

### ۴) اورلای داخل بازی (طبق طراحی دقیق)
- کشیدن از لبهٔ چپ در حالت افقی → باز شدن ستون ۹ زبانهٔ عمودی، هر زبانه رنگ نیمه‌شفاف مخصوص، ورود دونه‌دونه با انیمیشن جهشی.
- هر زبانه دکمهٔ بستن دارد؛ پنل بعد از ۳۰ ثانیه بی‌حرکتی خودکار بسته می‌شود (شمارشگر روی پنل).
- لمس زبانه → صفحهٔ همان زبانه با «سرخوردن جادویی» کنار ستون باز می‌شود؛ بقیهٔ صفحه برای بازی فعال می‌ماند؛ ستون و پنل کنار هم می‌ایستند؛ فضای بینشان شفاف است.
- زبانهٔ انتخابی مشخص است؛ زدن دوبارهٔ همان زبانه پنل را می‌بندد؛ زبانهٔ جدید، قبلی را بسته و سپس باز می‌شود.
- زبانه‌ها: سریع، جهان، بازیکن، آیتم‌ها (۳۸ آیتم)، توانایی‌ها (۱۲ افکت)، ماب‌ها (۲۶ ماب)، دستور آزاد، مدیریت سرور و پشتیبانی — در مجموع بیش از ۱۲۰ دکمهٔ تک‌لمسی.
- حالت «تک‌نفره»: شبیه‌ساز صحنهٔ بازی داخل اپ (آسمان/روز و شب، آب‌وهوا، هاتبار، ماب‌ها) که همهٔ دستورها واقعاً رویش اثر می‌گذارند.

### ۵) صدا
- **صدای زن فارسی همراه اپ** («آوا»): ۱۰ گفتار ضبط‌شده برای راهنمای همهٔ صفحه‌ها داخل بستهٔ نصب؛ بدون وابستگی به موتور گفتار گوشی.
- دستیار صوتی در نوار پایین همهٔ صفحه‌ها: دکمهٔ «راهنما» متن همان صفحه را می‌خواند؛ متن گفتار هم‌زمان نمایش داده می‌شود.
- کنترل صوتی (در تنظیمات روشن می‌شود): دکمهٔ میکروفن در همهٔ صفحه‌ها؛ نرمال‌سازی فارسی و تطبیق فرمایشی با زبانه‌ها و دکمه‌ها؛ در بازی، کلمهٔ بیداری «آتا» + اسم زبانه + متن دکمه.
- **محدودیت صادقانه:** شناسایی گفتار (ورودی صدا) در وب‌ویو اندروید به سرویس شناسایی دستگاه/گوگل وابسته است؛ اگر در دسترس نبود، اپ ورودی متنی جایگزین می‌دهد. گفتار خروجی اما از فایل‌های همراه اپ پخش می‌شود.

## آزمون‌ها
- `tests/atta.test.js` — ۱۴ آزمون: کاتالوگ میزبان‌ها، اعتبارسنجی ساخت، پورت/آدرس، مراحل استقرار، اجرای ۲۰+ دستور، بکاپ، ذخیره‌سازی، نرمال‌سازی و تطبیق گفتار.
- `tests/browser/atta.spec.js` — ۷ آزمون مرورگری: مسیر کامل ساخت تا اتصال، رفتار دقیق اورلای (باز شدن با لبه و کشیدن اشاره‌گر، تعویض زبانه، بستن با زبانهٔ تکراری، آزاد بودن لمس بقیهٔ صفحه، اجرای دستور و اثر آن روی هاتبار، بستن خودکار)، پنل مدیریت.
- اجرا: `npm test` و `npx playwright test tests/browser/atta.spec.js`.

## محدودیت‌های مهم
1. **ساخت واقعی روی میزبان‌ها شبیه‌سازی است.** این اپ یک بستهٔ آفلاین است؛ برای استقرار واقعی روی اترنوس/پبل‌هاست و… اتصال به API کلیددار هر میزبان لازم است که در این نسخه پیاده نیست. همهٔ منطق مدیریت (کنسول، دستورها، بکاپ، وایت‌لیست) روی نمونهٔ محلی کاملاً کار می‌کند.
2. **اورلای روی خود بازی ماینکرافت** از جنس وب‌ویو ممکن نیست (نیازمند سرویس رسم روی برنامه‌ها در اندروید است). نسخهٔ حاضر اورلای را داخل اپ و روی شبیه‌ساز بازی اجرا می‌کند؛ برای اورلای روی بازی واقعی باید همان منطق به یک سرویس بومی `SYSTEM_ALERT_WINDOW` منتقل شود (کد رفتاری اورلای در `src/atta/overlay.js` آماده و جداست).
3. نصب روی گوشی/شبیه‌ساز در این محیط تست نشده؛ امضا و ساختار فایل بررسی شده است (مانند رویهٔ نسخه‌های قبلی پروژه).
4. کلید امضا در گیت نیست؛ برای آپدیت همان کلید قبلی لازم است.

## ساخت دوبارهٔ APK
```sh
bash scripts/setup-android-tools.sh          # یک‌بار؛ نیازمند اتصال شبکه
# ساخت کلید (یک‌بار): مانند دستورهای داخل همان اسکریپت، برای .tools/atta-local.p12 با نام مستعار atta
read -s -p 'Keystore password: ' KEYSTORE_PASSWORD; echo; export KEYSTORE_PASSWORD
bash scripts/build-atta-apk.sh
```

```
src/atta/game.js             شبیه‌ساز صحنهٔ بازی واکنش‌پذیر
src/atta/engine.js           موتور: ذخیره‌سازی، استقرار، اجرای دستورها، تطبیق گفتار

```

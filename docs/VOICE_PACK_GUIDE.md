# راهنمای بستهٔ صوتی «آوا» (Voice Pack)

این سند توضیح می‌دهد که چطور یک بستهٔ صوتی زن فارسی واقعی بسازید و داخل
MineAva نصب کنید. «آوا» از این بسته مستقیماً پخش صدا می‌کند و لازم نیست به
موتور TTS سیستم یا اینترنت وابسته باشد.

> **نکتهٔ صادقانه:** خود فایل‌های صوتی لایسنس‌دار (WAV/OGG) در این ریپو قرار
> ندارند؛ چون هم Licensing و هم حجم فایل اجازه نمی‌دهد. زیرساخت کامل نصب،
> اعتبارسنجی و پخش واقعی داخل اپ فعال است.

---

## ۱. ساختار ZIP

یک فایل `.zip` بسازید که شامل دو بخش باشد:

```
my-voice-pack.zip
├── voice_pack.json
├── salam.wav
├── hello.wav
├── server-on.wav
├── backup.wav
└── LICENSE.txt        (اختیاری)
```

### `voice_pack.json`

```json
{
  "voice": "Ava",
  "language": "fa-IR",
  "speed": 1.0,
  "note": "صدای نمونه",
  "phrases": {
    "سلام": "salam.wav",
    "سلام! من آوا هستم": "ava-hello.wav",
    "خوش آمدی": "welcome.wav",
    "سرور روشن شد": "server-on.wav",
    "بکاپ آماده شد": "backup.wav",
    "خروجی آماده است": "output.wav",
    "خطا": "error.wav"
  }
}
```

- `voice`: نام صدای داخل اپ.
- `language`: اختیاری، معمولاً `fa-IR`.
- `speed`: اختیاری؛ فعلاً پخش مستقیم است و تأثیر ندارد.
- `note`: اختیاری؛ توضیح نسخه/لایسنس.
- `phrases`: **مهم**. هر کلید یک جمله/کلیدواژه است و مقدار آن نام فایل صوتی داخل ZIP.

## ۲. نوع فایل‌های صوتی پشتیبانی‌شده

| پسوند | پشتیبانی |
|---|---|
| `.wav` | ✅ |
| `.ogg` | ✅ |
| `.mp3` | ✅ |
| `.m4a` | ✅ |
| `.flac` | ✅ |

فایل‌ها باید با کلاینت اندروید قابل پخش باشند. اگر از ابزارهای آنلاین تبدیل
استفاده می‌کنید، نرخ نمونه‌برداری `22050 Hz` یا `44100 Hz`, مونو یا استریو،
خروجی `PCM 16-bit` برای WAV بهترین نتیجه را دارد.

## ۳. ساخت بسته با اسکریپت ساده (پایتون)

در ریشهٔ ریپو، فایل `tools/make_voice_pack.py` را ببینید. مثال:

```bash
cd tools
python3 make_voice_pack.py \
  --name "Ava" \
  --voice-dir /path/to/wavs \
  --output /sdcard/Download/MineAva/ava-voice.zip
```

اسکریپت:

1. فایل‌های WAV موجود در `--voice-dir` را می‌گیرد.
2. به‌ازای هر فایل، یک کلید فریز بر اساس نام فایل می‌سازد
   (`salam.wav` → `salam`, `ava-hello.wav` → `ava hello`).
3. از روی فایل `phrases_extra.json` در همان پوشه (اختیاری) فریزهای فارسی
   واقعی را اضافه می‌کند.
4. خروجی `.zip` را می‌سازد.

فعّال کردن صدای داخل اپ:

```
تنظیمات صوتی → 📦 وارد کردن بستهٔ صوتی زن فارسی (ZIP)
             → 🎤 استفاده از صدای داخل اپ: ON
```

## ۴. تست بدون داشتن ضبط صوتی واقعی

در «تنظیمات صوتی» دکمهٔ **«🎁 ساخت بستهٔ نمونهٔ داخل اپ»** وجود دارد. این
دکمه یک بستهٔ آزمایشی با تون‌های کوتاه WAV می‌سازد تا مسیر کامل
(Package → Install → Toggle → Playback) بدون هیچ فایل externaltest شود.
صدا در این حالت «آوا»ی واقعی نیست؛ اما کل مسیر فنی اندازه‌گیری می‌شود.
دکمهٔ **«📤 خروجی ZIP نمونه»** همان بسته را به `Download/MineAva` خروجی
می‌دهد تا بتوانید آن را باز کرده و WAVها را با صوت واقعی جایگزین کنید.

---

## ۵. قوانین مطابقت فریز

موتور پخش به این ترتیب فریز را انتخاب می‌کند:

1. **تطابق دقیق** کل جمله با یکی از کلیدهای `phrases`.
2. **تطابق بخشی**: اگر جملهٔ گفتاری شامل کلید باشد (مثلاً «سرور روشن شد»).
3. اگر هیچ‌کدام نبود، **اولین فریز** پخش می‌شود.
4. اگر بسته در دسترس نباشد/فایل نباشد، خودکار به TTS سیستم برمی‌گردد.

نشانه‌گذاری (»، ؟، !، 🙂، -، :، «») هنگام تطابق حذف می‌شود تا
«سرور روشن شد.» با کلید `سرور روشن شد` هم مطابقت کند.

---

## ۶. اعتبارسنجی هنگام نصب

اپ هنگام نصب ZIP این موارد را چک می‌کند:

- وجود `voice_pack.json`.
- غیرخالی بودن `phrases`.
- وجود هر فایل صوتی که در `phrases` به آن اشاره شده.
- مسیرهای خطرناک (`..`) رد می‌شوند.

اگر چیزی ناقص باشد، بسته حذف/پاک می‌شود و پیام خطای دقیق فارسی نمایش داده
می‌شود.

---

## ۷. استفاده در سایر صفحات

بعد از فعال‌سازی «صدای داخل اپ»، همهٔ پیام‌های متنی اپ (مثلاً «سرور روشن
شد»، «خروجی آماده است»، «بکاپ آماده شد») از همان بسته پخش می‌شوند.
برای جملات مهم خارج از لیست، هنوز TTS سیستم پشتیبان است.

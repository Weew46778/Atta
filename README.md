# MineAva — دستیار هوشمند و لانچر ماینکرافت (Android)

MVP اول یک اپ اندروید بومی (Kotlin + Android Views) برای:

- لانچر Minecraft Bedrock
- دستیار صوتی فارسی «آوا» (متن→گفتار، گفتار→متن)
- پنل اورلای کشویی از لبه چپ صفحه با زبانههای عمودی
- ساخت خودکار سرور (Local/VPS)
- **اجرای واقعی روی VPS از طریق SSH/SFTP** (اتصال، آپلود اسکریپت، اجرا با sudo، خروجی زنده)
- مدیریت سرور از راه دور (وضعیت سرویس، ریاستارت، لاگ، بکاپ دنیا، آمار RAM/دیسک/آپتایم)
- **مدیریت واقعی پکیجها روی سرور**: چک سلامت لینک (HTTP)، دانلود، آپلود SFTP، نصب/حذف، ریاستارت
- مدیریت پکیجها (پلاگین/ماد/شیدر/تکستچر) از لیست پیشنهادی
- سلامت دستگاه (رم، حافظه، دما، CPU، پاکسازی کش)
- تست سیستم و گزارش خطا با دکمه کپی به کلیپبورد
- دایرةالمعارف محلی ماینکرافت (جستجوی آفلاین) + اتصال هوش مصنوعی آنلاین (Gemini)
- **یادگیری پویا**: هر پاسخ آنلاین آوا در حافظهٔ شخصی `knowledge_extra.json` ذخیره میشود تا بعداً آفلاین جواب بدهد
- **تحقیق پویا**: دکمه «تحقیق و تکمیل دانش» در تنظیمات، همانند خواستهٔ شما چند موضوع ماینکرافت را آنلاین میپرسد و به دایرةالمعارف شخصی اضافه میکند
- **کنسول سادهٔ سرور**: ورودی فرمان + وضعیت سرویس روی VPS (اتصال واقعی به STDIN با screen/tmux هنوز در نسخه بعد است)

## Build

1. با Android Studio (Hedgehog یا جدیدتر) پروژه را باز کنید.
2. اگر فایل `gradle/wrapper` در ریپو نیست، اجازه دهید Android Studio خودش Gradle Wrapper را بسازد.
3. یک دستگاه/شبیهساز Android 7 (API 24) یا بالاتر انتخاب کنید.
4. `Run 'app'` را بزنید.

### SDK / Java
- Android `compileSdk 35`, `minSdk 24`, `targetSdk 35`
- Kotlin 1.9.24
- Android Gradle Plugin 8.5.2
- Java 11

### پلاگینهای موردنیاز
Android Studio اینها را auto-sync میکند:
```

```

## دسترسیها / زیرساخت

در اولین باز شدن، اپ از کاربر میخواهد:

- `RECORD_AUDIO` برای گفتگوی صوتی
- `POST_NOTIFICATIONS` برای سرویس اورلای
- `SYSTEM_ALERT_WINDOW` (نمایش روی برنامههای دیگر) برای پنل اورلای

## کلید هوش مصنوعی (اختیاری ولی مفید)

پاسخهای آفلاین از `knowledge_base.json` میآید. برای پاسخهای آنلاین/مکالمه، یک API key از
Google AI Studio بگیرید و در صفحه «تنظیمات هوش مصنوعی» (دکمه منوی اصلی) وارد کنید؛ اپ آن را در
`AppPrefs.geminiApiKey` نگهداری میکند.

## محدودیتهای آگاهانهٔ MVP

| بخش | وضعیت فعلی |
|---|---|
| لانچر بدراک | ✅ اجرا/یا هدایت به فروشگاه |
| پنل اورلای | ✅ جرئیات کشویی، زبانه، انیمیشن، جمع شدن خودکار ۳ ثانیه |
| گفتگوی صوتی فارسی | ✅ TTS + STT (وابسته به موتور دستگاه) |
| ساخت و اجرای واقعی VPS | ✅ SSH/SFTP، انتخاب کلید/پسورد، آپلود و اجرا، خروجی زنده |
| مدیریت از راه دور VPS | ✅ وضعیت سرویس، ریاستارت، لاگ (با کلید SSH ذخیرهشده) |
| تزریق مستقیم دستور داخل بدراک | ⛔ نیاز به API دستنخوردهٔ Mojang/شبیهساز داخلی؛ در نسخه بعد |
| اجرای سرور واقعی روی گوشی | ⛔ در MVP فقط دستور آماده/پیشخوان؛ نیاز به runtime دارد |
| مدیریت واقعی پکیج/ماکرو داخل سرور | ⛔ فعلاً لیست + چک ساده لینک؛ نسخه بعد |
| خودبهروزرسانی و دایرةالمعارف آنلاین خودران | ⛔ زیرساخت بهصورت Interface مستقر است؛ نسخه بعد |
| صدای زن فارسی داخل فایل اپ | ⛔ در این نسخه از TTS سیستم استفاده میشود؛ جایگزینی در نسخه بعد |

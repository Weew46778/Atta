# آتا — ماجراجویِ کوچکِ من (نسخهٔ ۳)

اپ فارسی و راست‌به‌چپِ کودکان: **کاملاً آفلاین، بدون تبلیغ، بدون حساب کاربری، بدون اجازهٔ اینترنت برای کودک**.
ساخته‌شده با وبِ خالص (بدون ابزار build) + پوشش اندرویدی WebView با پل گفتارِ بومی.

## چه چیزی داخل است

- **۱۰ اقلیم × ۲۰ مرحله = ۲۰۰ مرحلهٔ ماجراجویی** با سختیِ تدریجی، آزمون‌های سرعتی (باس) و جشنِ پایانِ اقلیم.
- **۳۷ نوع بازیِ تعاملی**: قصه، انیمیشن، معما، کلمه‌سازی، مثل‌ها، کارآگاهِ جمله، ریاضیِ قصه‌دار، الگو، ترازو، حافظهٔ اعداد/واژه/کارت، سمعکِ رنگین (سایمون)، تیزبینی، شمردنِ برق‌آسا، ترتیب، دسته‌بندی، نقشهٔ ایران، انتخابِ قهرمان، نفسِ آرامش، شناختِ احساس، صدای باور، خودشناسی، نقاشی، ریتم، خریدِ هوشمند و …
- **رادارِ ۹ مهارتی** + ۲۸ نشانِ افتخار + **۲۰۰ گنجِ دانستنی** (یک گنج برای هر مرحله) + نگارخانهٔ نقاشی‌های کودک.
- **چالشِ روزانه** (۳ بازی با جایزه) و **بازیِ آزاد** + ردیابی روزهای پیوسته.
- **نسخهٔ خردسال (۲–۳ سال)** با مینا، طوطیِ مهربان: ۲۰ جلسهٔ گفتاریِ هدایت‌شده (قصه + بازی + آهنگ + نکتهٔ گفتاردرمانی برای والدین)، ۱۲ دستهٔ واژه با هجابندی، ۱۲ سرودِ حرکتی، ۱۶ قصهٔ پنج‌جمله‌ای و ۶ نوع بازیِ لمسی.
- **گوشهٔ والدین**: ۱۶ درس‌نامهٔ مادر و ۱۲ درس‌نامهٔ پدر (متن + تمرین + چک‌لیست)، چرخهٔ ۱۰ روزهٔ حضورِ پدر با ثبتِ آیینِ روزانه، ۶ تمرینِ آرامشِ فوریِ والد، ۸ «جملهٔ داغ» برای لحظه‌های بحرانی، برنامهٔ روزِ خانواده و گزارشِ پیشرفتِ کودک.
- **راویِ فارسی**: TTS وب + پلِ بومیِ اندروید (AttaVoice) + میکروفنِ اختیاری برای تمرینِ گفتار (تشخیصِ گفتار روی خودِ دستگاه).

## ساختار

```
app/                 # اپ وب (بدون build)
  index.html  manifest.webmanifest  sw.js
  css/base.css       # طراحی یکپارچهٔ RTL
  js/                # ۱۷ ماژول: هسته، محتوا، موتورها، صفحه‌ها
  assets/fonts/      # Vazirmatn (OFL)
  assets/img/        # آیکون‌ها
android/atta/        # MainActivity + پل AttaVoice + آیکون‌های mipmap
scripts/build-atta-apks.sh   # ساخت ۵ APK بدون Gradle
releases/atta-v3/    # APKهای امضاشده
```

## اجرا

```sh
cd app && python3 -m http.server 8000   # یا هر سرور استاتیک
```

## ساخت APK (پنج نسخه)

```sh
bash scripts/setup-android-tools.sh        # یک‌بار: JRE + android.jar + aapt2 + d8
KEYSTORE_PASSWORD=... bash scripts/build-atta-apks.sh
```

نسخه‌ها: **همه‌کاره** (انتخاب درون‌برنامه‌ای)، **کاوشگر** (۴–۱۰ سال)، **خردسال** (۲–۳ سال)، **همراهِ مادر** و **همراهِ پدر** (بوت مستقیم در گوشهٔ والدین). همه آفلاین‌اند؛ فقط TTS/STT از موتورهای خودِ دستگاه استفاده می‌کند.

## حریم خصوصی

همهٔ داده‌ها در `localStorage` همان دستگاه می‌مانند. هیچ درخواستِ اینترنتی از سمت بازی زده نمی‌شود (در APK همهٔ درخواست‌های خارج از بستهٔ محلی مسدود است). میکروفن فقط با اجازهٔ صریح و برای تمرینِ گفتار روشن می‌شود.

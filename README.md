# 🎮 Atta UltraReal — تکستچرپک + شیدرپک فوق‌واقع‌گرایانه ماینکرفت بدراک

**نسخه ۲ — تمام تکستچرها ۵۱۲×۵۱۲ و عکس واقعی** 📸
**سازگار با:** Minecraft Bedrock 1.26.x (همچنین 1.21.120+) • **دستگاه هدف:** POCO X6 Pro ‏(Android 16) و هر گوشی که **Vibrant Visuals** را پشتیبانی کند ✅

---

## 📦 فایل‌های خروجی (پوشه‌ی `dist/`)

| فایل | چیست؟ |
|---|---|
| **`AttaUltraReal.mcpack`** (~۳۴ مگابایت) | ۲۱۶ تکستچر **۵۱۲ واقعی** (عکس طبیعی سیملس‌شده) + PBR کامل (هیت‌مپ برجستگی + فلزی/نوری/زبری/Sabsurface از خودِ عکس) + ~۷۴۰ صدای واقعی بلوک‌ها + رنگ‌بندی برگ/چمن طبیعی + پانورامای منوی اصلی |
| **`AttaVibrantShader.mcpack`** | شیدر واقع‌گرایانه برای Vibrant Visuals: نورپردازی خورشید/ماه واقعی، جوّ و رنگ آسمان طبیعی، درجه‌بندی رنگ سینمایی، آب با امواج واقعی و کاستیک |

## 🚀 نصب در ۳ قدم

1. هر دو فایل `.mcpack` را روی گوشی کپی کن و روی آن‌ها بزن → با Minecraft باز می‌شوند و خودشان ایمپورت می‌شوند.
2. در تنظیمات جهان (یا Global Resources) **هر دو پک را فعال کن**؛ ترتیب پیشنهادی: `Atta UltraReal` **بالاتر** از `Atta Vibrant Shader`.
3. **Settings → Video → Graphics Mode = Vibrant Visuals** را فعال کن. تمام! 🌅

> ⚠️ اگر گزینه‌ی Vibrant Visuals قفل بود، یعنی پک دیگری بدون قابلیت `pbr` فعال است — آن را خاموش کن. هر دو پک ما قابلیت `pbr` دارند.

## 🧱 پوشش تکستچرها (۲۱۶ تکستچر ۵۱۲ — همه‌ی گروه‌های اثرگذار)

- **خاک و پوشش زمین (عکس واقعی):** چمن (رو/کنار با تیغه‌های آویزان واقعی)، خاک، خاک درشت ترک‌خورده، خاک ریشه‌دار، پادزول (کف جنگل با برگ‌های افتی)، مایسلیوم، مسیر چمن، زمین کشاورزی خشک/خیس با شیار، گل خیس/خشک، خشت گل، خزه، سنگریزه، ماسه، ماسه‌ی قرمز، برف، یخ (سطح دریاچه‌ی یخ‌زده)، رس
- **سنگ‌ها (عکس واقعی):** سنگ، اندیزیت/دیوریت/گرانیت (+پولیش)، سنگ‌بر واقعی، سنگ‌بر ترک‌خورده/خزه‌دار، آجر قرمز، بدراک، ابسیدین
- **دیپ‌اسلیت (تخته‌سنگ تیره‌ی واقعی)، تاف، بازالت (ستون‌های واقعی!)، بلک‌استون (بازالت متخلخل)، کلسیت، دریپ‌استون** — با همه‌ی واریانت‌های آجری/پولیش‌شده و **همه‌ی وجه‌ها**
- **تنه‌ی واقعی درختان:** بلوط، توس (پوست سفید خالدار)، صنوبر، جنگل، آکاسیا، بلوط تیره، حرا، آلبالو (با لنتیسل‌های افقی)، بلوط روشن + **همه‌ی استریپ‌شده‌ها** + **مقطع عرضی واقعی با حلقه‌های سالانگی** برای هر گونه + پوست کناری هر تنه
- **همه‌ی تخته‌ها** (تخته‌ی چوبی واقعی با رنگ‌بندی هر گونه) + **برگ‌های عکسی** (تاج برگ واقعی با سوراخ‌های آلفا + نسخه‌ی مات برای Fancy)
- **سنگ‌های معدنی:** بستر عکس واقعی سنگ/دیپ‌اسلیت/ندراک + بلورهای معدنی فرو رفته با سایه‌نشانی — زغال، آهن، طلا، مس، ردستون، لاجورد، الماس، زمرد + نسخه‌ی دیپ‌اسلیت همه + کوارتز و طلای ندر
- **ند و اِند:** ندراک (توف قرمز واقعی)، نایلیوم خونی‌سا/وارپد (لایه‌ی خزه‌ی زنده روی ندراک)، خاک و ماسه‌ی روح، آجر ندر، بلوک وارپد (بافت سوزن‌برگ)، اندستون و آجرش
- **گل‌ها و گیاهان:** ۱۴ گل + ۶ گل دوتایی + علف/سرخس خشک/تاک/نی‌لوزم/نیلوفر (پروسیجرال اَبَر وضوح ۵۱۲)

## 🔊 صداهای واقعی به تفکیک جنس (۲۷۱ رویداد)

- **شیشه:** صدای واقعی خرد شدن شیشه • **سنگ/دیپ‌اسلیت/بازالت:** ضربه‌ی سنگی با ترک فیزیکی • **چوب:** توخالی تنه + ترک • **چمن:** خاک + سوت سبزه • **شن:** تیز • **ماسه:** سایش نرم • **برف:** کرانچ • **یخ:** صدای شکست یخ • **برگ‌ها:** خش‌خش • هر رویداد ۴–۶ واریانت تصادفی.

## 🌅 شیدر چه کار می‌کند؟

- خورشید طلوع/غروب نارنجی گرم + آسمان عمیق‌تر + هاله‌ی خورشید طبیعی • مه و افق نرم‌تر (پراکندگی رایلی) • درجه‌بندی رنگ سینمایی • **ردستون واقعاً می‌درخشد** و گلواستون نور می‌تاباند • برگ‌ها نور را عبور می‌دهند • آب با موج واقعی + کاستیک.

## ⚙️ نکات کارایی برای POCO X6 Pro (مهم برای نسخه‌ی ۵۱۲!)

تکستچرهای ۵۱۲ واقعی سنگین‌تر از نسخه‌ی قبلی‌اند؛ با این تنظیمات روان می‌گیری:
1. کیفیت Vibrant Visuals را روی **«Standard»** بگذار (تفاوت بصری کم، سرعت خیلی بیشتر).
2. Texture Quality داخل تنظیمات Vibrant Visuals → اگر گزینه داده، یک پله کمتر از Ultra.
3. سایه‌ها (Shadows) یک پله کمتر • حذف امواج آب: در پک شیدر `water/water.json` → مقدار `enabled` داخل `waves` را `false`.
4. Game Pass واقعی حافظه‌ی زیاد می‌خواهد — برنامه‌های پس‌زمینه را ببند.

## 🛠 توسعه/بازسازی

```bash
pip install --target=.deps pillow numpy scipy
PYTHONPATH=.deps python3 tools/generate_512.py     # ۲۱۶ تکستچر ۵۱۲ از عکس‌های واقعی
PYTHONPATH=.deps python3 tools/generate_sounds.py  # ۷۴۱ فایل صوتی ogg
PYTHONPATH=.deps python3 tools/build_packs.py      # شیدر JSON + منیفست + زیپ‌ها
```

**نحوه‌ی ساخت:** بلوک‌های غالبِ دنیا از **عکس‌های واقعی** ساخته شده‌اند (بُرش مرکزی → سیملس (تیل) → رنگ‌بندی به‌ازای هر متریال → استخراج هیت‌مپ از روشنایی → نقشه‌ی زبری از کنتراست). جزئیات ریزتر در حافظه‌ی پروژه.

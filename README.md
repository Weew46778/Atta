# Atta — لانچر و پنل اپراتور ماینکرفت 🎮🛠

اپ اندرویدی که **ماینکرفت را اجرا می‌کند** (نسخهٔ موبایل/بدراک و نسخهٔ جاوا از طریق PojavLauncher) و یک **پنل شناور (Overlay) کشویی از لبهٔ سمت چپ** روی بازی می‌گذارد تا هنگام بازی، ابزارها و امکانات اپراتور در دسترس باشد.

</div>

---

## ✨ چطور کار می‌کند؟

هنگامی که در حال بازی هستی، یک **خط سبزِ ظریف کنار لبهٔ چپ صفحه** دیده می‌شود:

- **لمس کوتاه** روی نوار → پنل با انیمیشن سر می‌خورد و باز می‌شود
- **کشیدن نوار به سمت راست** (به داخل صفحه) → پنل باز می‌شود
- **کشیدن نوار بالا/پایین** → جای دستگیره را عوض می‌کنی (موقعیت ذخیره می‌شود)
- داخل پنل **چهار زبانه** هست؛ لمس هر زبانه، صفحهٔ خودش را با **انیمیشن سرخوردن** باز می‌کند
- دکمهٔ **✕** یا کشیدن انگشت از داخل پنل به بیرون (لبهٔ چپ) → بسته می‌شود

پنل روی هر چیزی که بالای آن باشد اجرا می‌شود: بازی، سرور، حتی صفحهٔ اصلی گوشی.

## 🧰 زبانه‌ها

### ۱) ابزارها
کمک‌های سریع در حین بازی روی **بازیکن هدف** (`{p}`) که نامش را بالای صفحه می‌نویسی (پیش‌فرض `@s`):

| دسته | نمونه‌ها |
|---|---|
| گیم‌مود | خلاق، بقا، ماجراجویی، ناظر |
| آب‌وهوا | صاف، باران، رعدوبرق |
| زمان | سپیده‌دم، ظهر، غروب، نیمه‌شب |
| لوازم | الماس، ندرایت، زمرد، طلا، سیب طلایی، توتم، ایلیترا، بیکن |
| افکت | سرعت، شب‌بینی، بازیابی، قدرت، مقاومت، پرش، تنفس، نامرئی، پاک‌کردن |
| دستور دلخواه | هر دستوری را خودت بنویس و بفرست |

> ⚡ اگر به سرورِ شخصی وصل باشی (RCON) دستور **مستقیم اجرا** می‌شود؛ اگر نه، دستورهای چت‌پذیر در **کلیپ‌بورد کپی** می‌شوند تا در چت بازی Paste کنی (مناسب دنیای تکنفره/دنیای خودت).

### ۲) سرور — کنسول کامل سرورهای شخصی
- اتصال **RCON** به سرور خودت (هم روی همین دستگاه با `localhost`، هم روی سیستم دیگر شبکه با IP آن)
- **کنسول کامل** با ورودی/خروجی زنده برای دستورهای اپراتور (`op`، `ban`، `kick`، …) — بدون نیاز به باز بودن چت بازی
- دستورهای سریع: فهرست بازیکن‌ها، بذر دنیا، ذخیرهٔ فوری، help
- دکمهٔ «استاپ کامل سرور» با تأیید دو مرحله‌ای

### ۳) دنیا — مدیریت دنیا و بازیکن‌ها
- **سختی دنیا** (صلح‌آمیز تا سخت)
- **قانون‌های دنیا (Gamerule)** با لمس کوتاه/بلند: حفظ آیتم‌ها، چرخهٔ شبانه‌روز، آب‌وهوا، آتش، تخریب موب‌ها، زاییده‌شدن موب‌ها و…
- بذر دنیا، ذخیرهٔ فوری، تغییر هوا
- **مدیریت بازیکن‌ها**: اپ کردن، اپ برداشتن، بیرون کردن، بن، بخشیدن، وایت‌لیست (با اتصال RCON)

### ۴) تنظیمات
- ویرایش **اطلاعات سرور** (آدرس/پورت/رمز) + دکمهٔ **تست اتصال** + راهنمای روشن‌کردن RCON
- شفافیت پنل (اسلایدر)، عرض پنل (باریک/عادی/تمام‌صفحه)، لرزش
- توقف پنل

## 🚀 ساخت و نصب (Android Studio)

پروژهٔ اندروید استاندارد با Gradle است. کافی است:

1. **Android Studio** (نسخهٔ جدید) را نصب کن.
2. `File → Open` و پوشهٔ همین پروژه را انتخاب کن.
3. بگذار Gradle Sync تمام شود (اینترنت برای دانلود وابستگی‌ها لازم است).
4. `Run ▶` روی یک گوشی/شبیه‌ساز اندروید ۸ به بالا.

ساخت APK از خط فرمان:

```bash
./gradlew assembleDebug
# خروجی: app/build/outputs/apk/debug/app-debug.apk
```

> اگر فایل `gradle/wrapper/gradle-wrapper.jar` موجود نبود (برای اجرای `./gradlew` در ترمینال)، یکی از این راه‌ها:
> - فقط از داخل Android Studio بساز (نیازی به آن jar ندارد)، یا
> - فایل jar را از آدرس زیر در پوشهٔ `gradle/wrapper/` بگذار:
>   `https://raw.githubusercontent.com/gradle/gradle/v8.7.0/gradle/wrapper/gradle-wrapper.jar`
> - یا اگر `gradle` روی سیستم داری: `gradle wrapper` را در پوشهٔ پروژه اجرا کن.

## 📱 راه‌اندازی روی گوشی

1. بازی را از لانچر باز کن (`اجرا`) — اگر نصب نباشد دکمه به «نصب» تبدیل می‌شود و تو را به صفحهٔ نصب می‌برد.
2. بار اول: دکمهٔ **«اعطای اجازهٔ نمایش روی برنامه‌ها»** را بزن و اجازهٔ پنل شناور را بده.
3. کلید **پنل اپراتور** را روشن کن.
4. وارد بازی شو و از لبهٔ چپ بکش! 🎉

می‌توانی یک **کاشی در تنظیمات سریع** (بالای صفحه) هم اضافه کنی تا پنل را یک‌لمسی روشن/خاموش کنی.

### چه بازی‌هایی پشتیبانی می‌شود؟
| بازی | پکیج | توضیح |
|---|---|---|
| ماینکرفت موبایل (بدراک) | `com.mojang.minecraftpe` | نسخهٔ رسمی گوگل‌پلی |
| ماینکرفت جاوا | PojavLauncher (`net.kdt.pojavlaunch`) | لانچر متن‌باز جاوا روی اندروید |

## 🔌 اتصال RCON به سرور خودت (پیش‌نیاز زبانهٔ سرور)

سرورهایی که **خودت مدیریت می‌کنی** (جاوا یا بدراک):

```properties
# در فایل server.properties سرور:
enable-rcon=true
rcon.port=25575
rcon.password=یک_رمز_قوی_بگذار
```

سپس سرور را ری‌استارت کن و در پنل آدرس را بزن:
- سرور روی همین گوشی/کامپیوتر → `localhost`
- سیستم دیگر در خانه → IP همان سیستم (مثلاً `192.168.1.20`)
- سرور ابری (Aternos و…) → IP و پورت سرور

> ⚠️ برای اتصال از بیرون شبکه باید پورت روی مودم فوروارد شود — فقط روی شبکهٔ امن این کار را بکن.

## ❓ نکته‌ها و پرسش‌های پرتکرار

- **دستور کپی شد ولی در بازی کار نکرد؟** دستورهای `/give`، `/gamemode` و… در دنیای تکنفره فقط با **فعال‌بودن چیت‌ها** در چت اجرا می‌شود؛ در سرور هم باید اپراتور (op) باشی.
- **هنگام تایپ در کنسول، بازی مکث می‌کند؟** هر اپی که کیبورد باز کند همین است؛ بعد از بستن کیبورد بازی ادامه می‌یابد. برای دستورهای کوتاه از دکمه‌های آماده استفاده کن تا نیازی به تایپ نباشد.
- **پنل دیده نمی‌شود؟** در تنظیمات گوشی (مخصوصاً شیائومی/سامسونگ) اجازهٔ «نمایش روی سایر برنامه‌ها» و «اجرای خودکار پس از خاموش‌شدن صفحه/در پس‌زمینه» را برای Atta فعال کن.
- **این اپ به موجانگ وابسته نیست** و «ماینکرفت» علامت تجاری مالک آن است؛ Atta فقط ابزاری است که خودت روی دنیا/سرورِ خودت استفاده می‌کنی.

```
├── MainActivity.kt          # لانچر بازی + کلید پنل
├── core/AppPrefs.kt         # ذخیرهٔ تنظیمات
├── rcon/RconConnection.kt   # کلاینت RCON (کنسول سرور)
└── overlay/
    ├── OverlayService.kt    # سرویس پیش‌زمینهٔ پنل شناور
    ├── PanelHost.kt         # پنجرهٔ overlay، دستگیره، زبانه‌ها، انیمیشن‌ها
    ├── UiKit.kt             # المان‌های رابط پنل
    ├── OverlayTileService.kt # کاشی تنظیمات سریع
    └── tabs/                # چهار زبانه: ابزارها، سرور، دنیا، تنظیمات
```
